# Roadmap

## Phase 1 — Foundation

- Initialize the repository structure.
- Define product requirements and success metrics.
- Select data sources and model integrations.

## Phase 2 — Agent implementation

- Website Audit Agent v0.4: implemented.
- SEO Agent v0.1: implemented with technical backlog and page plans.
- Developer Agent v0.1: implemented with approval-gated implementation plans.
- Content Agent v0.1: implemented with page-specific content briefs and publication gates.
- Add prompt templates, structured outputs, and tests.
- Unified Growth Workflow v0.1: implemented with a package manifest and measurement framework.
- Inquiry Qualification Agent v0.1: implemented with A/B/C scoring, missing inputs, and approval-ready reply drafts.
- Sales Pipeline Report Agent v0.1: implemented with explicit milestone counts, blockers, and priority queues.
- Follow-up Agent v0.1: implemented with unsent Day 3/7/14/21/final sequences for A/B records.
- Analytics & Conversion Report Agent v0.1: implemented for approved local normalized exports.
- Extend operations with approved GA4/Search Console export adapters and recurring reports.

## Phase 3 — Validation

- Run controlled analyses against approved inputs.
- Review recommendation quality, traceability, and safety.
- Establish human approval gates.

## Phase 4 — Operations

- Generate recurring reports and prioritized growth backlogs.
- Measure approved changes against B2B acquisition outcomes.
